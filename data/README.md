# data/

CHARLS individual-level data are **not redistributed** in this repository,
in accordance with the CHARLS data use agreement.

Download the CHARLS 2011 baseline and 2013-2020 follow-up waves from
<http://charls.pku.edu.cn/en/> after registering, then build the analysis
extract and place it here as `CHARLS_2011.csv`.

See the main `README.md` and `R/01_prepare_data.R` for the required columns
and the cohort construction steps.
